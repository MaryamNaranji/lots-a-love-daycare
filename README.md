# Lots A Love Daycare Website

A colorful, mobile-friendly static website for Lots A Love Daycare in Potomac Station, Leesburg, Virginia.

## Files
- `index.html` — main website
- `reviews.html` — review/feedback page
- `styles.css` — full site styling
- `script.js` — mobile menu, enrollment email form, review email form
- `images/` — daycare photos

## GitHub + Vercel
Upload all files and the full `images` folder to the root of the GitHub repository. Vercel will automatically redeploy after changes are committed to `main`.

## Review page
The review page includes sample review wording clearly labeled as sample content. Replace those cards with real parent/guardian reviews only after receiving permission to publish them.

The feedback form opens the visitor's email application and prepares an email to `nazi157ranjbar@yahoo.com`. This provides a simple approval workflow without storing family information publicly.

## Privacy reminder
Only publish photos of children when you have appropriate parent/guardian permission to use those photos on a public website.
