# Lots A Love Daycare Website

A responsive static website for Lots A Love Daycare in Leesburg, Virginia.

## Files
- `index.html` – website content
- `styles.css` – design and responsive layout
- `script.js` – mobile navigation and footer year
- `images/` – daycare photo gallery and homepage images

## Deployment
This site is ready to deploy on Vercel directly from GitHub. Any new commit to the `main` branch will automatically update the live site.
