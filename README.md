# Lots A Love Daycare Website

Static daycare website with Vercel serverless functions for:
- enrollment inquiry emails to Nazi + parent confirmation
- review submission emails to Nazi + reviewer confirmation
- approve/publish or ignore review workflow
- approved review display on reviews.html

## Deploy
Upload all files and folders to the GitHub repository connected to Vercel.

## Required one-time setup
Read `SETUP_EMAIL_AND_REVIEWS.md` and run `supabase-setup.sql`.
