# Lots A Love Daycare Website

A responsive static website for Lots A Love Daycare in Leesburg, Virginia.

## Local files
- `index.html`
- `styles.css`
- `script.js`

## Deploy with GitHub + Vercel
1. Create a new GitHub repository named `lots-a-love-daycare`.
2. Upload the three website files to the repository.
3. Sign in to Vercel with GitHub.
4. Click **Add New > Project**.
5. Import the `lots-a-love-daycare` repository.
6. Framework Preset: **Other**.
7. Leave Build Command blank.
8. Leave Output Directory blank.
9. Click **Deploy**.

Vercel will publish the site and automatically redeploy whenever the GitHub repository is updated.
